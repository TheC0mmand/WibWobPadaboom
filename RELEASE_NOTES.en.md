# Release notes — July 27, 2026

**Documentation: [Français](RELEASE_NOTES.md) | English**

## New features

- all documentation rewritten in French with matching English versions;
- clear warning that only the English game version is supported;
- APK Builder interface and logs available in French or English;
- external translations stored in `CUSTOM_APK_BUILDER/lang/*.lang`;
- language selection displayed when the Builder starts and saved in its settings;
- Admin Client and APK Builder rebuilt from obscured intermediate sources;
- Windows launchers updated to use only the `-Obfuscated` executables.

## Public files

- `ADMIN_CLIENT/WibWobAdmin-Obfuscated.exe`
- `CUSTOM_APK_BUILDER/WibWobApkBuilder-Obfuscated.exe`
- `CUSTOM_APK_BUILDER/lang/fr.lang`
- `CUSTOM_APK_BUILDER/lang/en.lang`

## Warning

The Builder language selection does not translate Wibble Wobble. The supported source APK and game remain in English.
